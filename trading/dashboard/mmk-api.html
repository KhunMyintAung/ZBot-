Parameters

Nameဥပမာအဓိပ္ပာယ်
codeUSD,THB,MM-16PAEလိုချင်တဲ့ Rate တွေပဲ (comma ခြား)။ မထည့်ရင် အားလုံး။
amount100ပြောင်းချင်တဲ့ ပမာဏ။ ထည့်ရင် convert အဖြေ ပါလာမယ်။
fromUSDပြောင်းမယ့် ငွေ (default USD)။ MMK လည်း ရ။
toMMKရလဒ် ငွေ (default MMK)။

ဥပမာ Requests

GET /api/mmk                                   # all rates
GET /api/mmk?code=USD,THB                      # only USD and THB
GET /api/mmk?amount=100&from=USD&to=MMK       # 100 USD in MMK
GET /api/mmk?amount=1000000&from=MMK&to=USD   # 1,000,000 MMK in USD
GET /api/mmk?code=USD&amount=50000&from=THB    # one rate + conversion

Rate fields

Fieldအဓိပ္ပာယ်
codeRate ID (အောက်က ဇယား ကြည့်)
buy / sellဆိုင်က ဝယ်ဈေး / ရောင်းဈေး (MMK)။ ဆီ နဲ့ ကမ္ဘာ့ရွှေမှာ null
mid(buy + sell) ÷ 2 – Convert မှာ ဒါကို သုံး
valueဈေးတစ်ခုတည်း ရှိတာတွေ (ဆီ၊ XAU/USD)။ ကျန်တာ null
unitMMK, MMK/kyattha (ရွှေ ၁ ကျပ်သား), MMK/litre, USD/oz
categoryfx ပြင်ပဈေး · official ဘဏ်ဈေး · gold · essentials ဆီ
statefresh = ဒီနေ့ data · stale = ဟောင်းနေ (သတိထား)
stale_reason(top level) Source က Update မရရင်သာ ပါ။ နောက်ဆုံး ရထားတဲ့ data ကို ပြနေတာ။

Errors & Limits

Statusဘာကြောင့်
200OK
400amount ဂဏန်း မဟုတ် / from/to code မရှိ (ဥပမာ {"error":"no buy/sell rate for XYZ"})
429IP တစ်ခုက ၁ မိနစ်မှာ ၆၀ ကြိမ် ကျော်ခေါ်
503Source ကို ယူမရသေး (Server စတင်ချိန်)။ ခဏနေ ပြန်ခေါ်ပါ။

Data က ၁၀ မိနစ်ထက် မြန်မြန် မပြောင်းလို့ ၅–၁၀ မိနစ်တစ်ခါ ခေါ်ရင် လုံလောက်ပါတယ်။ Response ကို ၅ မိနစ် Cache လုပ်လို့ရ (Cache-Control: max-age=300)။

⚠️ Data အကြောင်း: ဈေးနှုန်းတွေကို mmktoday.com (SetLive နဲ့ ဘဏ် website များ) ကနေ ယူထားတာပါ။ ကိုးကားချက် (reference) သာဖြစ်ပြီး ဆိုင်/ဘဏ် အစစ်အမှန်ဈေးနဲ့ ကွာနိုင်ပါတယ်။ ငွေအများကြီး လဲလှယ်ရင် ဆိုင်/ဘဏ်မှာ ပြန်စစ်ပါ။ Website မှာ ပြရင် Source ကို ဖော်ပြပေးပါ။ Prices are a reference only; source: mmktoday.com.
